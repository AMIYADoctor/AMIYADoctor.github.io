计算机网络实验一：静态网页制作简介

发布于：2026年10月6日 | 作者：黄耔乐PB24000352

一、实验背景

本次计算机网络实验一的核心任务是掌握静态网页的制作方法，了解 HTML 与 CSS 的基本语法，并熟悉将网页部署至云端服务器的完整流程。作为初学者，这是我第一次亲手构建并发布网页，旨在通过实践加深对网络协议和前端基础的理解。

二、实验内容与介绍

在网页结构设计上，我采用了 HTML5 标准，利用 <div> 标签进行了模块化布局。网页内容划分为自我简介、家乡简介、生活分享、基本信息以及友情链接等块状卡片，并利用 CSS 添加了圆角、阴影以及平滑滚动效果。首屏设计为全屏封面，配以白色标题文字，底部通过超链接成功发布了这篇博客。

在云端部署方面，我将网页托管至 GitHub Pages。通过建立与用户名匹配的仓库（AMIYADoctor.github.io）并上传所有 HTML 文件与图片资源，实现了网页的公网访问。实验过程中，我学会了使用 F12 开发者工具排查图片 404 问题，深刻体会了从本地开发到云端部署的完整链路。
