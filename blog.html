我的第一篇博客

发布于：2026年10月6日 | 作者：黄耔乐

大家好！这是我第一次尝试在 GitHub Pages 上发布博客。以前觉得建网站是一件特别高深的事情，这次计算机网络实验一，让我亲手体验了从写 HTML 代码到把网页挂载到云端，再到别人可以通过网址访问的全过程。

刚开始接触 HTML 的时候，看到一堆尖括号完全不知道从哪里开始。但在一步步尝试之后，我发现原来只需要学会几个基本的标签（比如标题 h1、段落 p、图片 img），就能搭建出自己的小天地。

在制作主页的过程中，CSS 的块状设计和阴影效果真的非常神奇。只加了 border-radius 和 box-shadow 几个属性，网页就瞬间从“90年代风格”变成了“现代简约风”。未来我会继续努力，学习更多前端知识，争取把网页做得更漂亮！
